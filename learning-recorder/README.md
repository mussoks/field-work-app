# 학습용 화면녹화 · 캡쳐 (Windows 11) — 프로토타입

ERP 자동화 AI 학습 데이터를 모으기 위한 화면 녹화·캡쳐 프로그램입니다.
AI가 영상을 **프레임 단위로** 보거나 캡쳐 이미지를 볼 때 **"여기를 클릭했다"** 를 확실히 알 수 있게 만드는 데 초점을 맞췄습니다.

## 실행 방법

| 방법 | 설명 |
|---|---|
| **exe 받기 (권장)** | GitHub → Actions → `learning-recorder (Windows build)` → 최신 실행 → **Artifacts** 의 `LearningRecorder-windows` 다운로드 → `LearningRecorder.exe` 실행 |
| 직접 빌드 | Python 3.10+ 설치 후 `build.bat` 더블클릭 → `dist\LearningRecorder.exe` |
| 개발 실행 | `run.bat` 더블클릭 (가상환경 자동 생성) |

> ERP가 **관리자 권한**으로 실행 중이면 이 프로그램도 *관리자 권한으로 실행* 해야 단축키·클릭 감지가 동작합니다 (Windows 보안 정책).

## 요청 기능

### 🎬 녹화
- **해상도**: FHD(1920×1080) / HD(1280×720) 선택. 4K 모니터는 선택한 크기로 축소하고 비율은 유지합니다.
- **프레임**: 30fps / 15fps 선택.
- **용량 최소화**: H.264(x264) CRF 압축. `저용량 / 표준 / 선명` 중에서 고르며, 글자가 읽히는 선에서 가장 작은 `표준`을 권장합니다. ERP 화면은 정지된 부분이 많아서 테스트에서는 1080p 7초 영상이 **약 124KB**(1분에 약 1MB)였습니다. 선택 옵션으로 녹화 후 한 번 더 압축할 수도 있습니다.
- **마우스 포인터 상시 표시**: 흰 화살표에 검은 테두리를 두르고, 둘레에 **노란 하이라이트 원**을 그립니다.
- **클릭 표시 (AI 인식용)**
  - 왼쪽 클릭은 **빨간 원 + 십자선 + `L-CLICK`**, 오른쪽 클릭은 **파란 원 + `R-CLICK`** 으로 표시합니다.
  - 더블클릭은 `DOUBLE`, 드래그는 시작점→끝점 선과 `DRAG`, 휠은 화살표와 `SCROLL UP/DOWN` 으로 표시합니다.
  - 표시는 **0.8초 동안 유지**됩니다(설정 가능). 그래서 15fps에서도 짧은 클릭이 프레임 사이에서 빠지지 않고 12프레임 넘게 남습니다.

### 📸 캡쳐
- **단축키 캡쳐**(사용자가 지정): 마우스 포인터 위치에 **클릭 지점 표시(원 + 십자선) + ✔ 번호 배지** 를 워터마크처럼 찍습니다.
- **각주**: 캡쳐 직후 마우스 근처에 입력창이 뜨고, 입력한 내용은 **체크 배지 바로 아래** 박스에 찍힙니다. 나중에 목록을 더블클릭해 고칠 수도 있습니다(원본에서 다시 그림).
- **번호 규칙**: 한 세트 안에서는 1, 2, 3… 순서로 번호가 붙고, **세트 종료** 단축키를 누르면 다음 캡쳐가 **새 폴더에서 1번부터** 시작합니다.

### 저장 위치
`바탕화면\학습용캡쳐\` 폴더를 자동으로 만듭니다. 바탕화면이 OneDrive로 옮겨진 경우도 실제 바탕화면 위치를 찾아 씁니다.
```
학습용캡쳐\
├─ 녹화\
│   ├─ 녹화_20261123_143012_1080p_30fps.mp4
│   └─ 녹화_20261123_143012_1080p_30fps.events.json   ← 클릭 좌표·프레임 번호 타임라인
└─ 캡쳐_20261123_150210_구매발주 등록\
    ├─ 01.png, 02.png, 03.png …     ← 클릭 표시 + 번호 + 각주
    ├─ 원본\01.png …                ← 표시 없는 원본 (AI 학습용 쌍 데이터)
    ├─ steps.json                   ← 단계별 좌표·버튼·창 제목·각주
    └─ 가이드.html                   ← 단계별 매뉴얼 (브라우저로 열기)
```

### 기본 단축키 (설정 탭에서 변경 가능)
| 기능 | 기본값 |
|---|---|
| 캡쳐 | `Ctrl + Shift + 1` |
| 캡쳐 세트 종료 (번호 초기화) | `Ctrl + Shift + 2` |
| 녹화 시작 / 정지 | `Ctrl + Shift + R` |
| 녹화 일시정지 / 재개 | `Ctrl + Shift + P` |

## 국내 프로그램을 참고해 추가한 기능

| 참고한 프로그램 | 추가한 기능 |
|---|---|
| 반디캠: 좌/우 클릭 시 빨강/파랑 원, 커서 노란 하이라이트 | 같은 색 규칙을 적용하고 더블클릭·드래그·휠 구분을 더함 |
| 반디캠·오캠: 영역 지정 녹화, 일시정지, 시작 카운트다운 | 영역 지정, 일시정지/재개, 3초 카운트다운 |
| 알캡처: 캡쳐 목록 관리, 지정 폴더 자동 저장 | 세트별 캡쳐 목록, 각주 수정, 마지막 캡쳐 취소 |
| 픽픽: 스탬프 삽입 | ✔ + 번호 스탬프를 자동으로 찍음 |
| 매뉴얼 자동 생성 도구들 | **클릭할 때마다 자동 캡쳐** 모드, 가이드.html 자동 생성 |

AI 학습 용도에 맞춰 더 넣은 기능은 다음과 같습니다.
- **이벤트 로그(.events.json)**: 클릭마다 `영상 시간 / 프레임 번호 / 영상 내 x,y / 버튼 / 활성 창 제목 / 프로그램명` 을 기록합니다. 영상 화면과 정답 좌표를 그대로 맞춰 볼 수 있습니다.
- **키 입력 표시**: `Ctrl + S`, `Enter`, `Tab` 같은 키를 화면 아래에 표시하고 로그에도 남깁니다. `특수키만` 이 기본값이며, 비밀번호가 영상에 남지 않도록 일반 글자는 기록하지 않습니다.
- **녹화·캡쳐 화면에서 자기 창 숨김**: 이 프로그램 창(각주 입력창, 상태바 포함)은 영상과 캡쳐에 찍히지 않습니다. Windows 10 2004 이상에서 동작합니다.
- **원본/표시본 쌍 저장**: 같은 화면을 표시 없는 원본과 정답 표시본으로 함께 저장합니다.

### events.json 예시
```json
{ "fps": 30, "width": 1920, "height": 1080, "scale": 1.0,
  "events": [
    {"t": 1.843, "frame": 55, "type": "mouse_down", "button": "left", "x": 253, "y": 128,
     "window": "구매발주 등록 - OO ERP", "process": "erp.exe"},
    {"t": 3.107, "frame": 93, "type": "key", "key": "Ctrl + S"},
    {"t": 4.526, "frame": 135, "type": "mouse_down", "button": "left", "double": true, "x": 380, "y": 265}
  ]}
```

## 알려진 제한 (프로토타입)
- 한글 입력은 IME 특성상 키 로그에 영문 키로 기록됩니다(`전체` 모드일 때). 기본값인 `특수키만` 모드에서는 상관없습니다.
- 커서는 표준 화살표 모양으로 그립니다. I-빔이나 손가락처럼 실제 커서 모양은 반영하지 않습니다.
- 오디오는 녹음하지 않습니다(용량 최소화, AI 학습에 필요 없음).
- exe를 처음 실행할 때 Windows SmartScreen 경고가 뜰 수 있습니다(서명되지 않은 실행 파일). `추가 정보 → 실행` 을 누르세요.

## 구조
```
src/
├─ main.py       GUI (tkinter), 각주 입력창, 영역 선택, 카운트다운, 상태바
├─ recorder.py   mss 화면 캡처 → 오버레이 → ffmpeg(libx264) 파이프 인코딩, 이벤트 로그
├─ overlay.py    포인터/클릭/드래그/휠/키 입력 그리기 (OpenCV)
├─ capture.py    캡쳐 표시·각주 렌더링 (Pillow, 맑은 고딕), 세트/번호 관리, 가이드 생성
├─ input_hub.py  전역 키보드·마우스 후킹(pynput), 사용자 단축키
├─ winutil.py    DPI 인식, 커서 위치, 활성 창, 캡처 제외, 바탕화면 경로
└─ selftest.py   자가 진단 (--selftest): 실제 화면 녹화 + 캡쳐 검증
```
