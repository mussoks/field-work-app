# 학습 레코더 (Windows 11) — v0.2

ERP 업무 화면을 **AI 자동화 학습 데이터**로 모으는 화면 녹화·캡쳐 앱입니다.
AI가 영상을 프레임 단위로 보거나 캡쳐를 볼 때 **"여기를 클릭했다"** 를 확실히 알 수 있게 만들고,
클릭 좌표·누른 버튼 이름까지 **바로 학습에 쓸 수 있는 데이터(JSON)** 로 함께 저장합니다.

## 설치

| 방법 | 설명 |
|---|---|
| **설치 파일 (권장)** | GitHub → Actions → `learning-recorder (Windows installer)` → 최신 실행 → Artifacts 의 **`LearningRecorder-Setup`** → `LearningRecorder-Setup-0.2.0.exe` 실행 |
| 직접 빌드 | Python 3.10+ 와 [Inno Setup 6](https://jrsoftware.org/isdl.php) 설치 후 `build.bat` → `dist\LearningRecorder-Setup-0.2.0.exe` |
| 개발 실행 | `run.bat` |

- **관리자 권한 없이** 사용자 계정에 설치돼요(회사 PC 가능). 시작 메뉴·바탕화면 바로가기, 제거 프로그램이 함께 설치됩니다.
- 설치할 때 **"Windows 시작 시 트레이에서 자동 실행"** 을 고르면 켜자마자 단축키를 쓸 수 있어요.
- 서명되지 않은 설치 파일이라 SmartScreen 경고가 뜰 수 있어요 → `추가 정보 → 실행`.
- ERP가 **관리자 권한**으로 실행 중이면 이 앱도 관리자 권한으로 실행해야 단축키가 동작합니다.

## 화면 구성

밝은 회색 바탕에 흰 카드, 큰 제목, 파란 주 버튼, 토글 스위치, 친근한 존댓말 문구로 구성했습니다.

| 메뉴 | 내용 |
|---|---|
| 🏠 홈 | 녹화 시작 · 지금 캡쳐 바로가기, 오늘 녹화/캡쳐 수, 모은 클릭 데이터 수, 사용 용량, 최근 기록 |
| 🎬 녹화 | 녹화 범위(모니터/영역), 해상도·프레임·압축, AI 표시 옵션, 개인정보 가리기, 하단 고정 **녹화 시작** 버튼 |
| 📸 캡쳐 | 작업 이름, **다음 번호**, 이번 세트의 캡쳐 목록(썸네일·각주 수정), 캡쳐 옵션 |
| 🗂️ 보관함 | 녹화·캡쳐 기록을 썸네일과 함께 보기, 열기/폴더/삭제 |
| ⚙️ 설정 | 단축키 변경, 저장 위치, **클릭 표시 미리보기**, 트레이·알림 |

녹화 중에는 화면 위에 작은 **녹화 바**(시간 · 클릭 수 · 일시정지 · 끝내기)가 뜨고, 이 바와 앱 창은 **녹화·캡쳐에 찍히지 않아요**.

## 기능

### 🎬 녹화
- **FHD / 720p**, **30 / 15fps**, 압축 `저용량 · 표준 · 선명` (표준 기준 1분에 약 1~2MB)
- **포인터 상시 표시**(흰 화살표 + 노란 원), **클릭 표시**: 왼쪽 빨강 `L-CLICK`, 오른쪽 파랑 `R-CLICK`, `DOUBLE`, `DRAG`, `SCROLL`
  - 표시가 0.8초 유지 → 15fps에서도 12프레임 이상 보임
- 키 입력 표시 (`Ctrl + S`, `Enter` …, 기본은 단축키만)
- **클릭 장면 모으기** ⭐ : 클릭할 때마다 *클릭 직전 원본 화면* + *표시된 화면* 을 이미지로 저장하고 `annotations.jsonl` 로 묶음
- **누른 곳의 이름 기록** ⭐ : Windows UI Automation 으로 클릭한 요소의 이름·종류를 기록 (예: `'저장' 버튼`)
- 3초 카운트다운, 일시정지/이어서, 영역 지정(멈춘 화면 위에서 드래그)

### 📸 캡쳐
- 단축키를 누르면 마우스 위치에 **클릭 지점 표시 + ✔ 번호 배지 + 각주**
- 캡쳐 직후 뜨는 각주 카드에 **누른 버튼 이름으로 추천 각주**가 미리 채워져 있음 (Enter 저장, Esc 건너뛰기, 최근 각주 칩)
- 번호는 세트 안에서 1, 2, 3…, **세트 끝내기** → 다음 캡쳐는 새 폴더에서 1번부터
- **클릭할 때마다 자동 캡쳐**(매뉴얼 자동 생성), **마지막 캡쳐 지우기** 단축키
- 표시 없는 원본도 저장 → 원본/정답 이미지 쌍

### 🔒 개인정보 가리기 ⭐
거래처명·주민번호처럼 남기면 안 되는 영역을 드래그로 정해두면 **녹화 영상·클릭 장면·캡쳐(원본 포함)** 모두 모자이크됩니다.

### 기본 단축키 (설정에서 변경)
| 기능 | 키 |
|---|---|
| 캡쳐 | `Ctrl + Shift + 1` |
| 캡쳐 세트 끝내기 (번호 초기화) | `Ctrl + Shift + 2` |
| 마지막 캡쳐 지우기 | `Ctrl + Shift + Z` |
| 녹화 시작 / 끝내기 | `Ctrl + Shift + R` |
| 녹화 일시정지 / 이어서 | `Ctrl + Shift + P` |

## 저장 구조 (바탕화면\학습용캡쳐)
```
학습용캡쳐\
├─ 녹화\녹화_20261127_143012_1080p_30fps\
│   ├─ 녹화_….mp4              클릭 표시가 그려진 영상
│   ├─ 녹화_….events.json      클릭/키 타임라인 (시간·프레임 번호·좌표·창·UI 요소)
│   ├─ thumb.jpg
│   └─ 클릭장면\
│       ├─ 001_원본.png  001_표시.jpg …
│       └─ annotations.jsonl   ← 한 줄 = 한 번의 클릭 (학습 데이터셋)
└─ 캡쳐_20261127_150210_구매발주 등록\
    ├─ 01.png 02.png …          ✔ 번호 + 각주
    ├─ 원본\01.png …
    ├─ steps.json · dataset.jsonl
    └─ 가이드.html               단계별 매뉴얼
```

### annotations.jsonl 한 줄 예시
```json
{"image": "003_원본.png", "marked": "003_표시.jpg", "frame": 105, "t": 3.5,
 "action": "click", "x": 380, "y": 265, "x_norm": 0.19792, "y_norm": 0.24537,
 "window": "구매발주 등록 - OO ERP", "process": "erp.exe",
 "element": {"name": "저장", "type": "ButtonControl", "type_ko": "버튼", "automation_id": "btnSave"},
 "instruction": "'저장' 버튼 클릭"}
```

## 알려진 제한
- UI 요소 이름은 ERP가 Windows UI Automation 을 지원할 때만 기록돼요(자체 그리기 화면은 비어 있을 수 있음 — 좌표 기록은 그대로).
- 한글 입력은 IME 특성상 `전체` 키 표시 모드에서 영문 키로 보여요.
- 커서는 표준 화살표 모양으로 그려요(I-빔·손가락 모양 미반영). 오디오는 녹음하지 않아요.

## 구조
```
src/
├─ main.py            진입점 (단일 실행, 오류 기록, --selftest / --ui-smoketest)
├─ controller.py      앱 로직 (후킹·녹화·캡쳐 → Qt 시그널), 보관함
├─ ui/                PySide6 화면: theme(디자인 토큰), widgets, pages, overlays, main_window
├─ recorder.py        화면 캡처 → 오버레이 → ffmpeg(H.264), 이벤트 로그, 클릭 장면 데이터셋
├─ overlay.py         포인터/클릭/드래그/휠/키 그리기
├─ capture.py         캡쳐 표시·각주 렌더링, 세트/번호, 가이드·dataset.jsonl
├─ uia.py             클릭한 UI 요소 정보 + 추천 각주
├─ masking.py         개인정보 모자이크
├─ input_hub.py       전역 키보드·마우스 후킹, 사용자 단축키
└─ assets/            아이콘, Pretendard 글꼴(OFL)
installer/LearningRecorder.iss   Inno Setup 설치 스크립트
```
